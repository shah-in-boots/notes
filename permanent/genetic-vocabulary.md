Vocabulary to remember in clinical genetics

# Basic vocabulary

phenotype $\rightarrow$ clinical presentation

genotype $\rightarrow$ specific DNA sequence

mutation $\rightarrow$ major functional change

polymorphism $\rightarrow$ DNA sequence change

exonic $\rightarrow$ coding region

intronic $\rightarrow$ non-coding region

alleles $\rightarrow$ different versions of the same gene, inherited one from each parent

homozygous $\rightarrow$ identical alleles

heterozygous $\rightarrow$ different alleles

# Mutations

SNP (single nucleotide polymorphism) $\rightarrow$ synonmous (DNA change without AA change), missense (changes AA), nonsense (premature stop codon)

insertion/deletion $\rightarrow$ "indel" with or without frameshift

CNV $\rightarrow$ copy number variants


# Clinical patterns

monogenic $\rightarrow$ mutation in a single gene can cause a disease phenotype

polygenc $\rightarrow$ variants in many genes are thought to contribute to the phenotype

genetic heterogeneity $\rightarrow$ mutations in different genes can cause similar phenotypes (or diseases)

penetrance $\rightarrow$ extent to which individuals with the same genotype express the same phenotype

incomplete penetrance $\righttarrow$ individuals carrying a mutation do not have the phenotype

variable expressivity $\rightarrow$ variations in the phenotype with similar mutations (i.e. SCN5a causes Brugada, LQTS, and other conduction system disease)

# Inheritance

autosomal dominant $\rightarrow$ single copy of mutation is sufficient to cause disease

autosomal recessive $\rightarrow$ affected individuals inherit mutant alleles from both parents... 

- consanguinity $\rightarrow$ inherit the same allele
- compound heterozygosity $\rightarrow$ inherit different disease alleles

X-linked $\rightarrow$ mutation is on X chromosome, meaning males are predominantly affected (e.g. Duchenne's muscular dystrophy)

mitochondrial $\rightarrow$ maternal inheritance, has syndrome pattern
